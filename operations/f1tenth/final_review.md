# 독립 검토와 수정

읽기 전용 별도 검토에서 중요한 경로 문제 2개와 로그 수집 문제 1개를 확인했다.

- Compose wrapper의 상대 데이터 경로가 프로젝트 디렉터리 변경 때문에 잘못 해석됨: bags 실제 연결에서 절대 자산 경로를 정하고 전달하도록 수정.
- Gazebo plugin 생성 위치와 검색 위치 불일치: distro/CPU별 artifacts 경로에서 build/ctest/plugin lookup을 함께 사용하도록 수정.
- FAST-LIO 로그 복사 경로가 옛 src/FAST_LIO를 가리킴: AAC의 실제 소스 Log 경로로 수정. 로그 보존의 회귀이므로 함께 해결했다.

두 wrapper 회귀 검사는 수정 전에 실패했고 수정 후 통과했다. 전체 정리·별칭·wrapper 검사는 11/11 통과했다. 미룬 검토 항목은 없다.

검토에서 하드웨어 동작·실제 AGX 배포·제어기 수식은 판단하지 않았다. 이번 작업은 파일 통합이며 해당 동작을 추가로 검증했다고 표현하지 않는다. Docker와 C++ 검사는 검토 당시 실행 중이었으므로 최종 결과는 verification.json과 로그에 별도로 기록했다. C++의 core_parity 실패는 원본 소스를 같은 새 artifact로 빌드해도 동일한 값으로 재현되며 이번 정리에서 수식·허용치를 변경하지 않았다.
