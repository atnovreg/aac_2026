# 2026-11-11 젯슨 수동 조작 준비 결과

## 현재 위치

젯슨 AGX Orin에 ROS Humble 수동 조작 소프트웨어를 배포하고 ARM 네이티브
빌드를 마쳤다. 아직 지상 주행 준비 완료가 아니다. 마지막 검사에서 VESC USB
장치가 사라져 실제 구동 채널의 텔레메트리 재확인이 남았다. 작업 중 모터나
서보를 움직이는 명령은 보내지 않았다. 실행 중인 시험 프로세스는 종료했다.

젯슨에서 미리보기 실행:

```bash
~/f1tenth-manual dry-run
```

VESC 배터리 전원과 젯슨 USB를 다시 연결한 뒤 읽기 검사:

```bash
~/f1tenth-manual check
```

미리보기에서는 하드웨어 드라이버가 실행되지 않는다. 실제 구동은 별도의
바퀴를 띄운 관찰 시험이 필요하다. 서보 출력은 모든 모드에서 분리돼 있다.
세부 조작/빌드 설명: `system/f1tenth_manual/README.md`.

## 확인한 것

- Ubuntu 22.04.5, aarch64, AGX Orin Developer Kit, ROS Humble.
- 실제 USB DualSense 인식 및 중립 ROS 입력 90개, 미리보기 ERPM 0 유지.
- 실제 SDL 매핑: × b1, ○ b2, R1 b5, 왼쪽 X a0, 오른쪽 Y a5.
  기존 PS4 기본값과 달랐다. a4는 놓았을 때 +1인 트리거다.
  해당 매핑을 설정에 반영했고 실제 버튼을 누르는 대조 시험은 남았다.
- 선택 ROS 패키지 6개 네이티브 빌드 성공.
- 실제 ROS 자동 테스트 15개 통과: 조이스틱 안전 10, 전체 미리보기 경로 3,
  연결 검사 1(상태 7가지), 실제 드라이버 온도 전달 1.
- 시리얼 가상 장치로 온도 누락을 먼저 재현했다(75°C 입력 → ROS 0°C).
  상류 드라이버 두 필드 수정 후 FET 75°C / 모터 31°C 전달을 확인했다.
- 관찰 준비 플래그 없는 `drive` 실행은 종료 코드 2로 거부됐다.
- VESC USB가 없을 때 연결 검사는 상태 샘플 0개로 실패했다.
  실제 전압/온도/채널 117 확인 성공으로 해석하면 안 된다.

안전 동작: 유효 입력 0.3초 초과 시 정지 명령과 해제, 새 ○ 누름으로 재허용,
× 우선, R1을 놓으면 0, 자동 명령 무시, 잘못된 입력 거부.
변환값은 명목 최대 ±1384 ERPM, 드라이버 한도 ±2000 ERPM이다.
실제 차량 속도 및 제동 거리를 보정하거나 검증한 값이 아니다.

## 작업 중 판단과 검토 범위

1. 기존 PC 체크아웃 대신 별도 worktree에서 작업하고 젯슨 원본은 백업했다.
   경로를 혼동하면 이전 소스를 실행할 수 있으므로 위 실행 링크를 사용한다.
2. 연속 진행 요청에 따라 소프트웨어 배포를 진행했다. 물리 구동은 시작하지
   않았다. 이 범위 해석이 다르면 배포 파일을 백업으로 복원할 수 있다.
3. 기본 PS4 매핑 대신 실제 SDL 매핑을 설정했다. 잘못된 매핑은 다른 조작을
   만들 수 있으므로 물리 버튼 대조가 끝나기 전 지상 주행 완료로 간주하지 않는다.
4. USB가 없는 동안 실제 장치 호환성과 채널 확인은 미완료로 남겼다.
   무시하면 검증하지 않은 제어 경로로 시험하게 된다.
5. 실제 제동 거리·조립 상태의 입력/USB 손실 정지·서보 전원/신호/보정은
   물리 시험으로 남겼다. 이를 생략하면 예상치 못한 움직임이나 정지 실패가 가능하다.
6. 기존 자동 명령 전달 경로는 이번 수동 설정의 검증 대상이 아니다.
   수동 런처는 이를 무시한다. 다른 런처에서 쓰면 별도 안전 검증이 필요하다.
7. 신뢰하는 로컬 조작자 한 명, 실행 세션 하나를 전제로 한다. localhost ROS
   도메인은 다른 로컬 발행자를 인증하지 않으므로 다른 프로세스가 명령을
   발행하면 게임패드 제한을 우회할 수 있다.

별도 검토자가 찾은 중요 문제 1건(온도 필드 누락)은 재현 후 수정했고
전체 시험이 통과했다. 미뤄둔 경미한 코드 지적은 없다.

## 이어서 할 일

1. VESC 전원/USB 재연결 → `check`에서 채널 117, 전압, 오류, 온도 확인.
2. 모터를 제어하지 않는 미리보기에서 실제 ○/×/R1와 스틱 방향 대조.
3. 바퀴를 띄우고 관찰하는 저속 전후진/정지/입력 손실 시험.
4. 조향 서보의 현재 연결, BEC 규격, 출력 가능 여부를 확인하고 중심/끝점 보정.
5. 조향과 정지 경로 확인 후 저속 지상 수동 주행.
