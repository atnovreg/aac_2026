# F1TENTH 연구주제 탐색 기준과 계획

기록일: 2026-11-10. 사용자가 기억해 달라고 요청한 교수님 지침과 이를 실행할 조사 계획 초안.
아직 문헌 검색·연구실 선정·신규성 검증을 수행한 결과가 아니다.

## 후속 대화에서 정한 우선 방향

사용자는 여섯 원칙을 개별 과제로 모두 수행하는 방식이 어렵다고 하여 가장 간단한 주제 탐색 방식을 요청했다.
아래의 간단한 흐름을 우선 사용하고, 본문의 상세 계획은 필요할 때 참고한다.

추가로 전달한 지도 방향: 큰 데이터셋이나 범용적인 환경에서 검증하거나,
이미 검증된 방법을 우리 차로 가져오는 방향을 적용한다.
두 경로를 모두 필수로 수행해야 한다는 뜻으로 해석하지 않는다.

실행 부담을 줄이기 위한 제안은 다음과 같다.

1. 공개 데이터·벤치마크 또는 여러 환경에서 검증 근거가 있고, 코드·모델·센서 조건이 우리 플랫폼에 맞는 방법 하나를 고른다.
2. 원 논문의 설정·지표에서 가능한 범위의 재현을 확인하고, 우리 차의 기록 데이터·실차에 적용한다.
3. 성능이 달라지는 조건 하나를 찾는다. 센서 보정·동기화·구현 문제를 먼저 배제하고 남은 문제를 연구 질문으로 삼는다.
4. 관련 후속 연구와 다른 분야의 아이디어를 확인해 개선 하나를 제안한다. 단순 이식·설치만으로 논문 기여가 성립한다고 가정하지 않는다.
5. 기존 방법과 개선 방법을 같은 조건에서 비교한다. 가능하면 원래 공개 평가 조건과 실차 조건을 함께 사용해 개선과 부작용을 확인한다.

후보를 검토할 핵심 질문 세 가지:

- 어디서 얼마나 검증되었는가? 데이터 크기뿐 아니라 조건의 다양성과 독립적인 평가를 확인한다.
- 우리 차에 가져올 수 있는가? 센서·입력·연산 자원·데이터 접근성과 코드 사용 조건을 확인한다.
- 옮겼을 때 남는 문제가 연구로 다룰 만한가? 재현·측정 가능성, 가까운 선행연구와의 차이, 구현 결함 여부를 확인한다.

건지광장 한 장소의 결과만으로 범용성을 주장하지 않는다.
공개 데이터 평가만으로 실차 폐루프 주행 성능을 입증했다고 주장하지 않는다.
교수님의 여섯 원칙은 방법 선정, 계보·한계 확인, 문제 분석과 개선 아이디어 탐색 안에 녹여서 사용한다.

## 사용자 맥락과 교수님 지침

F1TENTH 하드웨어를 세팅하고 건지광장 한 바퀴 자율주행을 진행하는 프로젝트를 활용해 논문 주제를 찾는다.
완주 여부나 실차 준비 완료 여부는 이 기록만으로 확정하지 않는다.

교수님이 준 여섯 가지 원칙:

1. 분야의 큰 흐름을 파악한다. 한 분야 안에서만 찾으면 이미 연구된 주제가 많으므로 서로 다른 연구축이 만나는 지점을 본다.
2. 최신 논문이 직접 지적한 약점을 수집한다.
3. 논문 하나가 아니라 계보를 본다.
4. 가장 잘하는 랩을 찾아 논문 흐름을 따라간다.
5. 방법 안에서도 빈틈을 찾을 수 있다.
6. 서로 다른 연구 흐름의 교차점을 노린다.

앞으로 이 프로젝트의 연구주제를 조사·평가할 때 위 원칙을 기준으로 사용한다.
연구실 명성이나 단일 논문의 성능만으로 주제를 선택하지 않는다.

## 제안하는 조사 방식

현장 문제에서 출발하는 조사와 문헌·연구실에서 출발하는 조사를 병행한다.
큰 흐름을 넓게 지도화한 뒤, 계보와 한계로 좁히고, 교차 가설을 현장에서 검증한다.
아래 수량과 일정은 초기 작업량 제안이며 사용자와 확정한 제약이 아니다.

### 0. 실험 자산과 현장 문제 정리

- 사용 가능한 센서, 연산 장치, 위치 추정·계획·제어 구성, 기록 데이터와 실차 반복 실험 가능 시간을 정리한다.
- 저장소 문서상 MID-360·RealSense, FAST-LIO, 건지광장 경로, MPCC 작업이 있다. 실제 장착·구동·기록 가능 여부는 별도로 확인한다.
- 주행 구간별 위치 추정 상태, 경로 오차, 속도, 조향, 처리 지연, 개입·실패와 당시 조건을 함께 기록한다.
- 외부 위치 기준이 없다면 실제 위치 오차라고 주장하지 않는다. 경로 추종 오차도 추정 위치에 의존함을 명시한다.
- 후보 문제가 하드웨어 보정·동기화·구현 결함인지 먼저 확인한다. 기존 방법을 제대로 적용해도 남는 문제를 연구 가설로 삼는다.

산출물: 실험 자산표와 재현 가능한 현장 문제 카드 3~5개.

### 1. 큰 연구 흐름 지도 만들기 — 원칙 1

탐색축 예시: 위치 추정·지도 / 계획·제어 / 불확실성·실패 감지 / 실차 배포·환경 변화.
각 축에서 무엇을 최적화하고 어떤 가정을 두며 다른 모듈에 어떤 정보를 넘기는지 비교한다.
레이싱 외 야외 이동로봇·장기 자율주행 등 인접 분야도 조사 범위에 넣는다.
첫 탐색은 최근 약 3년을 중심으로 하되 기초 논문과 중요한 이전 연구는 연도 제한 없이 읽는다.

산출물: 축별 핵심 문제·가정·평가 조건을 정리한 한 장짜리 연구 지도.

### 2. 축별 핵심 연구실 선정 — 원칙 4

- 특정 축에서 연결된 후속 연구를 지속하는지 확인한다.
- 관련 조건에서의 실차 증거, 비교 실험의 질, 코드·데이터 접근성을 평가한다.
- 최신 후속 연구에서 남은 문제가 무엇인지 확인한다.
- 모든 분야를 통틀어 최고인 랩 하나를 고르기보다, 축별 2~3개씩 총 4~6개 후보에서 시작한다.

산출물: 연구실별 연구 질문, 대표·후속 논문, 공개 자산, 우리 실험과의 연결을 담은 표.

### 3. 논문 계보 추적 — 원칙 3

관심 계열마다 문제를 제기한 연구 → 대표 해법 → 한계를 보완한 후속 연구 → 최신 상태를 연결한다.
참고문헌을 거슬러 올라가는 조사와 인용한 후속 논문을 찾는 조사를 모두 수행한다.
각 연결에 바뀐 가정, 새로 해결한 한계, 여전히 남은 한계를 적는다.
대표 계보 3~4개를 고르고 각각 핵심 논문 3~5편을 우선 읽는다.

산출물: 계보별 변화표와 반복해서 남는 가정 목록.

### 4. 근거가 있는 약점 장부 작성 — 원칙 2

각 논문에 대해 제목·연도·버전·링크, 절·페이지, 저자가 명시한 한계,
그 한계가 발생하는 조건, 평가하지 않은 조건, 후속 연구의 해결 여부,
우리 플랫폼에서 재현 가능한지를 기록한다.
초록과 결론뿐 아니라 방법의 가정, 실험 설정, 실패 사례, 부록을 확인한다.
저자가 직접 명시한 한계와 우리가 추론한 한계, 단순히 평가하지 않은 조건을 구분한다.
장부에 기록한 한계는 최신 후속 연구로 다시 확인한다.

산출물: 근거 위치가 있는 한계 장부. 예비 목표 10~15건.

### 5. 방법 내부의 가정과 연결부 점검 — 원칙 5

입력 → 상태 추정 → 계획 → 제어 → 평가 과정을 따라 숨은 가정이 현장에서 성립하는지 확인한다.
예를 들어 추정값만 전달하고 신뢰도를 버리는지, 센서·연산 지연을 일정하다고 보는지,
모델 파라미터를 고정하는지, 평가 환경이 실제 운용 조건을 대표하는지를 묻는다.
이는 점검 질문이며 현재 코드나 특정 논문의 결함을 확인했다는 뜻은 아니다.

산출물: 가정–깨지는 조건–관측 증거–최소 재현 실험 표.

### 6. 연구축을 연결해 후보 가설 작성 — 원칙 6

각 후보를 다음 한 문장으로 만든다.

> 기존 A 계열은 B 조건을 가정하므로 C 상황에서 D 문제가 남는다.
> E 계열의 아이디어를 적용·수정하면 F 메커니즘으로 이를 줄일 수 있고, G 실험으로 검증한다.

탐색 예시이며 신규성·적합성을 확인하지 않은 조합:

- 위치 추정 불확실성 × 속도 계획·제어.
- 센서·연산 지연 × 예측 제어.
- 환경 변화·분포 이탈 감지 × 지도 갱신·재위치 추정 판단.

단순히 두 알고리즘을 붙였다는 설명으로 끝내지 않는다.
어떤 새 문제를 해결하는지, 연결에 어떤 기술적 난점이 있는지, 효과가 나는 이유를 명시한다.

산출물: 후보 3~5개. 문헌 교차 검색과 최소 재현 실험 후 1~2개로 축소.

## 후보 선정과 탈락 기준

각 후보 카드에는 다음을 포함한다.

- 연구 질문과 반증 가능한 가설.
- 기존 계보, 가장 가까운 선행연구, 아직 남아 있다고 보는 한계와 근거.
- 새로 기여할 내용 한 문장.
- 실제 센서·연산 자원·지도·데이터에서의 구현 가능성.
- 비교 방법, 평가 조건, 반복 실험, 기여 요소를 제거한 실험.
- 평가 지표와 위치 기준 등 측정의 한계.
- 첫 1주 검증 실험과 중단 기준.

우선 통과해야 할 조건: 직접 관련 선행연구와 차이를 설명할 수 있음,
반복 가능한 조건과 평가가 있음, 기간·장비 안에서 비교 실험을 할 수 있음.
통과 후보를 문제 중요도, 차별성 근거, 실험 가능성, 자원 적합성, 결과 해석 가능성으로 비교한다.
검색되지 않았다는 사실을 미연구의 증거로 취급하지 않는다.
주장과 직접 관련된 반복 실험과 변형 조건을 설계하며, 주제와 무관한 성능 지표를 늘리지 않는다.

## 초기 2주 일정 제안

- 1~2일: 실험 자산·현장 문제와 큰 흐름 지도 작성.
- 3~4일: 축별 핵심 연구실과 대표 논문 선정.
- 5~7일: 논문 계보와 근거 있는 한계 장부 작성.
- 8~10일: 방법 내부 가정 점검, 교차 후보 작성, 가까운 선행연구 재검색.
- 11~14일: 실차 준비 상태에 따라 로그 재생·시뮬레이션·실차 중 가능한 최소 실험 수행. 후보 1~2개의 연구 제안서 각 1쪽 작성.

하드웨어 준비가 지연되면 확보된 데이터와 로그 재생으로 할 수 있는 검증부터 수행한다.
최종 산출물은 논문 목록보다, 근거와 실험 설계가 있는 연구 질문 1~2개다.
