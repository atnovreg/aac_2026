# Slash model v2 — 2026-09-23

기본 23/86 기어, 내부비 2.72, Velineon 3500kV, 3S 11.1V는 유지한다.

변경:

- 모터 속도 외피는 min(KV × 전압, 제조사 기계 회전수 50,000rpm)을 사용한다. 기어비와 바퀴 반경으로 속도로 변환한다. 코스의 speed_max와 별개이며, 선형 구동력 감소 형태 자체는 여전히 가정이다. 11.1V에서는 KV × V = 38,850rpm이라 새 회전수 상한은 활성화되지 않는다.
- 음수 구동 입력은 후륜 제동으로 정의한다. 별도 motor_brake_current_limit=30A 가정값을 사용하고 tanh(vx/0.2)로 정지 근처에서 부드럽게 0으로 만든다. 후진 구동 및 실제 회생제동 전기 모델이 아니다. 정지에서 음수 입력이 차량을 뒤로 밀던 동작을 제거했다.
- 가속/제동 전류가 다를 때 입력 변화 한계는 둘 중 큰 전류 기준으로 제한한다.
- 부분 model_parameters 설정을 기본 제원과 병합한다. 질량·외형만 수정하면 관성은 기존 균일 직사각형 근사로 다시 계산하며, 명시적으로 지정한 관성은 유지한다. 유한값, 양수 조건, lf+lr=축거 등을 확인한다.
- NumPy plant와 CasADi 예측 모델은 동일한 수식 경로를 사용한다. 실행 설정에는 vehicle_model_revision을 기록한다.

확인된 제원과 추정 동역학은 config/vehicles/slash_58276_74.yaml의 parameter_evidence에 분리했다. 질량 3.56kg, 마찰 0.9, 조향 한계/응답, 구동 효율은 새 실측 없이 바꾸지 않았다. 조향 액추에이터 지연, 배터리 전압 강하, 하중 이동, VESC 실제 전류 설정은 아직 모델링/식별되지 않았다.

이 변경은 실차 식별 완료가 아니다. 제조사 제원으로 제한 가능한 부분과 명백한 제동 동작을 보완한 모델이다. 기존 결과 파일은 수정하지 않는다.

검증: 기존 MPCC 테스트, Slash 숫자/심볼 일치, 후륜 마찰 한계, 독립 제동 전류, 정지 제동, 제동 소산성, 회전수 상한, 부분 제원 병합, 잘못된 축거 거부. 통합 주행 결과는 results/건지광장/mpcc_comparison/20260923_model_v2/에 저장한다.
