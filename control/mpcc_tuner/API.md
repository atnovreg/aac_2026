# Local tuner API
All JSON, same origin, no dependencies. API errors {error:string}, non-2xx. POST content type application/json.
GET /api/catalog -> {fields:[{key,label,symbol,default,min,max,scale:"log"|"linear",group:"main"|"advanced",description}], tracks:[{id,label,length_m,map_revision}], defaults:{track:"edited_inner",speed_max:4,weights:{flat key:number}}, baseline_label:string, speed_limits:{min:1,max:26.8,step:0.1}}
Weight flat keys: contour,lag,progress,yaw_rate,terminal_contour_multiplier,terminal_yaw_rate_multiplier,input_drive,input_steering,input_progress,increment_drive,increment_steering,increment_progress. All numerical. Fields give ranges.
GET /api/track/{id} -> {id,label,length_m,center:[[x,y]],left:[[x,y]],right:[[x,y]],map:{url:"/map.png?track={id}",extent:[xmin,xmax,ymin,ymax],revision:string},baseline:{trajectory:[row],summary:{...},weights:{flat}}}
row order: [t,x,y,yaw,vx,vy,yaw_rate,progress,current_fraction,steering,vtheta,lateral_offset,constraint_violation,solver_time_s,controller_cycle_time_s,simulation_cycle_time_s].
POST /api/jobs body {track,speed_max,weights:{flat}} -> 202 {id}; 409 if running. Immutable settings until rerun.
GET /api/jobs/{id}?after=-1 -> {id,status:"building"|"running"|"finalizing"|"completed"|"failed"|"cancelled",track,weights,speed_max,frames:[{index,step,time_s,state:[x,y,yaw,vx,vy,r,progress],samples:[row],prediction:[[x,y]],progress_m}],summary:null|object,error:null|string,run_path:null|string}. after is last received frame index. Frames include all rows accumulated since previous event (every 10 simulation steps). prediction belongs to start of its last step, state to end. Client can keep frames for replay. After terminal, GET with after=-1 reloads whole saved replay.
Summary at end: completed_lap,status,simulation_time_s,physical_progress_m,track_length_m,max_abs_lateral_offset_m,rms_lateral_offset_m,max_corridor_violation_m,controller_cycle_time_ms:{mean,p95,max},controller_deadline_misses,steps,failure. Missing metrics/null possible on failure. Only call simulation_time_s lap time if completed_lap.
POST /api/jobs/{id}/cancel {} -> {ok:true}; wait until terminal. No process kill from browser.
GET /api/history -> {jobs:[{id,track,status,created_at,weights,speed_max}]} recent persisted jobs, including terminal failures.
GET /api/jobs/{id}/download -> attachment JSON with settings, summary and frames; source solver logs saved at run_path.
Display scope: Offline provisional Slash model, 3.56kg ±30A, desktop controller timing excludes browser/IPC; map includes assumed floor. No guaranteed real-car/high-speed result. Stage qc and effective terminal qc=qc*multiplier shown. Editing during a run affects next run only. No live-weight-change claim.

Registered courses: `edited_inner` (default; 20260917_inner_focus edited area/track), `outer`, `left_inner`, `both_inner` (original v5 area/tracks). Each course has its own matching baseline. GET `/map.png?track={id}` returns that course map; legacy `/map.png` retains the original map. Unknown IDs return404. Loading historical jobs must use their `track` ID, not the current default. Course map URL/revision changes are authoritative for image cache selection.
