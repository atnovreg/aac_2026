# 공통 기능

[workspace.py](workspace.py)는 소스 위치에서 상위 폴더의 `.f1tenth-workspace` 표식을 찾아 워크스페이스 루트를 구합니다. 모듈의 깊이가 달라져도 데이터·빌드 경로를 같은 루트에 연결하기 위한 공통 함수입니다.

여러 기능에서 실제로 공유하는 작은 기능을 이곳에 둡니다. 제어기·지도 처리처럼 담당 기능이 명확한 코드는 해당 모듈에서 관리합니다. 현재 공통 경로 검사는 [operations/tests](../operations/tests)에 있습니다.
